# AI 对话记录 05 · UI 交互、端到端测试与缺陷修复

## 阶段
用无头 Edge 做全章自动化测试、截图视觉审查，并修复发现的问题。

## 人类指令（要点）
- 交互 UI 必须无异常；要有多重折叠；截图要真实、可用于提交。

## AI 的测试设施
- `tools/cdp-lib.mjs`：基于 Node 内置 WebSocket 的极简 CDP 客户端。
- `tools/e2e.mjs`：自动走完八章、点击发送/滑块/模态、逐章全页截图、收集页面异常与 console error。
- 全部核心算法另跑 `tools/test-core.mjs`。

## 测试发现并修复的问题（真实记录）
1. **整页空白（严重）**：`js/ui/lab.js` 中三处 `el()` 调用括号错位、表格 tbody 多一个右括号，导致模块语法错误，整个 app.js 无法执行。用 `node --check` 定位后逐一修复，页面恢复。
2. **Service Worker 缓存为 0（严重）**：本地零依赖静态服务器在 Windows 下对 `GET /` 做路径归一化时返回 404，使 `cache.addAll` 失败。修复服务器对根路径处理；并让开机自检与离线章在首屏等待 SW 激活（最多 8 秒）后回写真实缓存数（19 个文件 / 146.0 KB）。
3. **基准表数字长尾**：均值显示为 `287.44333333333333`，统一改为 1 位小数。
4. **编解码耗时显示 0.0000 ms**：单次调用低于计时器分辨率，改为自适应批量计时（每批至少约 3 ms，再除以次数），得到真实亚毫秒数值。
5. **任务判决只有两态**：默认预算 15 J 时三层协议的 L2 也未送达，判决与动画自相矛盾。改为三态判定，默认预算调为 30 J，并让动画在能量耗尽瞬间冻结未送达部分。
6. **时间轴标签重叠**：“JSON 完整”标签与黄金窗口虚线重叠，改为按位置左右展开。
7. **自检行未回写**：`say()` 未返回 DOM 元素，导致 SW 状态行无法更新，修复返回值。
8. **gzip 文案口径**：“gzip 是 JSON 的 1.02×”表述拗口，改为同时给出绝对字节数与相对倍数。

## 最终结果
- 端到端：**零页面异常、零 console error**，页面内编码往返一致（monolithic/layered 均为 true）。
- 产出 10 张全章截图，选定 8 张放入 `screenshots/`。
